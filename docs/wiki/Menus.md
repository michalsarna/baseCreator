# Menus

The menu bar has seven menus: **File · Edit · Insert · Arrange · View · Settings · Help**. The layout is that of the other programs, without their **Machine** menu and the menu of their process.

* On **Windows and Linux** the menu bar is in the window. It is shown in the editor, not on the start screen.
* On **macOS** the menus are in the system menu bar, with the app menu **BaseCreator** (**About BaseCreator**, **Quit**) and **Window**.
* An entry that cannot be used now is grey. A switch has a tick when it is on.

## File

| Entry | Key | What it does |
|---|---|---|
| **New** | Ctrl+N | A new, empty drawing in a tab of its own. |
| **Open…** | Ctrl+O | A project, an SVG, a PDF or an Illustrator file in a new tab; a DXF, LightBurn or UGS file is imported. |
| **Open recent** | | The last 10 files; **Clear list** empties the list. |
| **Save** | Ctrl+S | Writes the project as `.cre`. |
| **Save as…** | Ctrl+Shift+S | Writes it under a new name. |
| **Page setup…** | | The size of the page. See [Page and Layers](Page-and-Layers). |
| **Import → …** | Ctrl+I for SVG | See [Import and Export](Import-and-Export). **Generate shape…** runs the generators of plugins. |
| **Export → …** | | See [Import and Export](Import-and-Export). |
| **Quit** | Ctrl+Q | Closes the program; every drawing with unsaved work is asked about first. |

**Print…** (Ctrl+P) prints the design on a paper printer or saves it as a PDF.

## Edit

**Undo** (Ctrl+Z), **Redo** (Ctrl+Y), **Copy** (Ctrl+C), **Paste** (Ctrl+V), **Duplicate** (Ctrl+D), **Delete** (Del), **Select all** (Ctrl+A).

## Insert

The tools that put new objects on the page, then **Generate shape…** and **Online clipart…**. New shapes go on the layer in use.

## Arrange

The same commands are in the right-click menu of a shape; they are explained on [Design Tools](Design-Tools).

* **Align left**, **Align centre (H)**, **Align right**, **Align top**, **Align centre (V)**, **Align bottom**, **Centre on bed** (the middle of the page), **Centre on each other**
* **Flip horizontal**, **Flip vertical**, **Rotate 90° CW**, **Rotate 90° CCW**
* **Group** (Ctrl+G), **Ungroup** (Ctrl+Shift+G), **Lock** (Ctrl+L), **Unlock** (Ctrl+Shift+L), **Bring to front**, **Send to back**
* **Edit nodes** (N), **Convert to path**
* **Union**, **Intersection**, **Subtract**, **Exclusive or**, **Offset shape…**, **Round corners…**, **Convert to curves**
* **Auto-join paths…**, **Close path with tolerance…**, **Dogbone / T-bone corners…**
* **Grid array…**, **Circular array…**, **Copy along path…**, **Text on path…**
* **Trim by shape…**, **Remove duplicates**, **Break apart**, **Simplify…**
* **Serial text…**, **Barcode / QR code…**, **Nest shapes…**, **Measure…**
* **Adjust image…**, **Trace image…**
* **Style trace…**: the selected picture drawn again as lines in one of 19 styles ([Style Trace](Style-Trace)).

## View

**Grid**, **Snap to grid**, **Snap to objects**, **Zoom in** (Ctrl++), **Zoom out** (Ctrl+-), **Fit bed to window** (Ctrl+Shift+0, the whole page), **Fit all objects** (Ctrl+Shift+9), **Auto-fit work area to window**, **Split view: side by side**, **Split view: one above the other**, **Single view**, **Background picture…**.

## Settings

| Entry | What it does |
|---|---|
| **View options…** | The grid, the colours of the work area, the thickness of the lines, **Show layer names**. |
| **Program options…** | **Look for a newer version when the program starts** (on by default). |
| **Plugins…** | See [Plugins](Plugins). |
| **Language** | 30 languages. |
| **Colour scheme** | 18 colour schemes, and two festive ones around Christmas, the New Year, Halloween, Easter and the Chinese New Year. |

## Help

**Quick guide** (F1), the guide inside the program. **Project page on GitHub**, **Download backup…** and **Restore from backup…** (see [Settings and Files](Settings-and-Files)), **Check for updates…**, **About**.

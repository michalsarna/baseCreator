# Ograniczenia

* **Bez maszyny:** nie ma urządzeń, połączeń, G-code, podglądu zadania ani kamery. Do tego służą LightCreator, MillCreator i PenCreator.
* **Tylko płaskie rysunki.** Model 3D i relief STL są w MillCreatorze.
* **Obrazy nie są eksportowane.** SVG, PLT i DXF zawierają obrysy; najpierw zwektoryzuj obraz.
* **Projekty UGS** przynoszą kształty na warstwach; posuwy i głębokości są pomijane.
* **Plik PLT** jest sprawdzony testami swojej treści, nie na prawdziwym ploterze ani w innych programach.
* **Brak podpisu płatnego konta deweloperskiego:** macOS i Windows ostrzegają za pierwszym razem. Zobacz [Instalacja](Instalacja).
* **Ustawienia strony** nie mają spadów ani opcji druku, a program nie drukuje.

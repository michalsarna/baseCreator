# 设计工具

BaseCreator 编辑形状所用的工具与 LightCreator、MillCreator 和 PenCreator 相同。快捷键见[键盘快捷键](Keyboard-Shortcuts-ZH)，菜单见[菜单](Menus-ZH)。

## 绘图

左侧的工具栏包括 **选择 (V)**（**Select (V)**）、**节点编辑 (N)**（**Node edit (N)**）、**矩形 (R)**（**Rectangle (R)**）、**椭圆 (E)**（**Ellipse (E)**）、**三角形 (Y)**（**Triangle (Y)**）、**星形 (S)**（**Star (S)**）、**多边形 (G)**（**Polygon (G)**）、**心形 (K)**（**Heart (K)**）、**螺旋 (I)**（**Spiral (I)**）、**直线 (L)**（**Line (L)**）、**折线 / 钢笔 (P)**（**Polyline / pen (P)**）、**文字 (T)**（**Text (T)**）、**平移 (H)**（**Pan (H)**）、**放大 (Z)**（**Zoom in (Z)**）、**缩小 (X)**（**Zoom out (X)**）和 **标尺 (M)**（**Ruler (M)**）。插入对象的工具也在 **插入**（**Insert**）菜单中，另外还有 **生成形状…**（**Generate shape…**，即插件的生成器）和 **在线剪贴画…**（**Online clipart…**）。

## 文字

选择 **文字 (T)** 并在页面上单击：会出现一段文字，同时 **属性**（**Properties**）标签页打开，其中有输入文字的字段。在那里可以设置字体、字号、粗体和斜体、字距和行距以及对齐方式。**转换为曲线**（**Convert to curves**）会把文字变成可以编辑节点的形状。新文字会沿用最近一次修改的文字的设置。

## 编辑

* 在形状上按**鼠标右键**会打开它的菜单：复制、编组、锁定、翻转和四分之一旋转、**排列**（**Arrange**）和 **形状运算**（**Shape operations**）子菜单，对于图片还有 **调整图像…**（**Adjust image…**）和 **描摹图像…**（**Trace image…**）。不适用于当前选择的条目显示为灰色。
* **连按两次 Esc**（半秒内）返回 **选择 (V)**。
* **撤销**（**Undo**）为每幅图最多保留 100 步。

## 形状运算

**并集**（**Union**）、**交集**（**Intersection**）、**减去**（**Subtract**）和 **异或**（**Exclusive or**）用于组合闭合形状。**偏移形状…**（**Offset shape…**）生成更大或更小的轮廓，**圆角…**（**Round corners…**）把角变圆，**转换为曲线** 用曲线代替直线，**转换为路径**（**Convert to path**）把矩形或星形变成路径，以便编辑其节点。

## 排列与复制

以下命令都在 **排列** 菜单中：

* **自动连接路径…**（**Auto-join paths…**）把端点距离小于容差的开放路径连接起来；**按容差闭合路径…**（**Close path with tolerance…**）闭合两端距离在容差之内的路径。**狗骨 / T 骨转角…**（**Dogbone / T-bone corners…**）为锐角添加缺口，适用于要铣削的形状。
* **网格阵列…**（**Grid array…**）按行和列复制。**环形阵列…**（**Circular array…**）把副本围绕所选内容的中心排布。最多生成 2000 个副本。
* **沿路径复制…**（**Copy along path…**）：先选择形状，**最后**选择路径。**路径文字…**（**Text on path…**）：先选择文字，最后选择路径；完成后它们是轮廓，不再是文字。
* **按形状修剪…**（**Trim by shape…**）：先选择线条，**最后**选择一个闭合形状。**删除重复项**（**Remove duplicates**）删除同一图层上轮廓相同的形状。**打散**（**Break apart**）把每个轮廓变成一个独立形状。**简化…**（**Simplify…**）去掉与线条距离在容差之内的点。
* **序列文字…**（**Serial text…**）：复制文字，其中的 `{n}` 依次递增；若使用 CSV 文件，则每一行复制一次。**条形码 / 二维码…**（**Barcode / QR code…**）把码以轮廓形式放到当前使用的图层上。
* **排样形状…**（**Nest shapes…**）按外框（而不是轮廓）把所选形状逐行排列紧凑。**测量…**（**Measure…**）显示所选内容的尺寸、位置、面积和长度；选中两个形状时，还显示它们之间的距离。

## 图片

**文件 → 导入 → 导入图像…**（**File → Import → Import image…**），或把图片拖放到窗口上，会打开导入对话框。**调整图像…** 用于修改页面上的图片，**描摹图像…** 把图片中的暗区或亮区转换为轮廓。图片本身没有轮廓，因此在描摹之前导出时会被略过。

**编辑图像…**（**Edit image…**，位于“排列”菜单、右键菜单以及 **图片风格**（**Picture styles**）标签页的橙色按钮中）为所选图片打开照片编辑器：**画笔**（**brush**）、**橡皮擦**（**eraser**，它涂上白色，相当于未被加工的材料）、**仿制图章**（**clone stamp**，先 Ctrl+单击（Mac 上为 Cmd+单击）指定复制来源，然后涂抹），以及对单击处周围相近灰度区域的 **填充**（**fill**）。颜色只有灰度。画笔的大小、硬度和不透明度以及填充的容差在左侧一栏中设置；撤销和重做可以来回切换。滚轮缩放，右键或中键移动图片。在按下 **应用**（**Apply**）之前，图纸不会有任何变化。

**转换为图像…**（**Convert to image…**，选中形状且其中没有图片时可用）把它们转换为一张图片。窗口中显示预览、分辨率（DPI）和图片尺寸、闭合形状是否填充以及线条宽度。**之后删除对象**（**Delete the objects afterwards**）在生成图片后删除这些形状；**隐藏对象**（**Hide the objects**）只是在预览中不显示它们的轮廓。图片会放在原来形状所在的位置，放到一个不含其他形状的图层上（删除形状时为形状所在的图层、含有图片的图层或一个空图层）。

**描摹图像**（**Trace image**）和 **风格描摹**（**Style trace**）窗口中的 **隐藏图片**（**Hide the picture**）会在预览中单独显示结果，不显示下面的图片。

**排列 → 风格描摹…**（**Arrange → Style trace…**）用 21 种风格之一（波浪线、螺旋、点画、排线、流线、一笔画……）以线条重绘图片：参见[风格描摹](Style-Trace-ZH)。

**视图 → 背景图片…**（**View → Background picture…**）把照片或扫描件放在图纸下方，以便在上面描画。它会随项目一起保存。

## 剪贴画库

**剪贴画**（**Clipart**）标签页里有现成的图片，图库与其他程序共享；**插入 → 在线剪贴画…**（**Insert → Online clipart…**）在互联网上搜索免费图片。

## 右侧面板

标签页有 **属性**、**图层**（**Layers**）、**剪贴画** 和 **描述**（**Description**）。参见[窗格与标签页](Panes-and-Tabs-ZH#右侧面板)。

## 标尺、选择与节点栏

* **标尺 (M)**：工具栏中位于 **缩小 (X)** 之后的工具。从一点拖到另一点，或单击两个点：图纸上方的一条线会以程序的单位显示长度、ΔX、ΔY 和角度。靠近形状节点的点会取该节点本身（否则在开启吸附时取网格点）。单击形状的直线段（矩形的一条边、一条直线）会测量该线段。测量结果会一直保留，直到下一次测量、按 **Esc** 或切换工具；图纸中的内容不会被改变。
* **使用工具时右键单击**（形状、钢笔、节点工具、标尺……）的作用等同于连按两次 **Esc**：返回 **选择 (V)** 且不选中任何对象；正在用钢笔绘制的线会先完成。使用选择工具时，右键单击仍和以前一样打开上下文菜单。
* **选中多个对象时**：除了整个选择范围的边框外，每个对象还有自己的细虚线边框。
* **节点栏**在名称后显示快捷键：**尖角 (C)**（**Corner (C)**）、**转为直线 (L)**（**To line (L)**）、**转为曲线 (S)**（**To curve (S)**）、**添加节点 (I)**（**Add node (I)**）、**删除节点 (D)**（**Delete node (D)**）、**倒圆 (R)**（**Round (R)**）、**断开 (B)**（**Break (B)**）。**打开 / 闭合**（**Open / close**）已移除：**断开 (B)** 用于打开路径，把路径的一端拖放到另一端上即可闭合路径。
* **不输出的图层**（其输出已关闭）中的对象会以向工作区颜色淡化的方式显示。

* **图片**：除 PNG、JPEG、BMP、GIF 和 WebP 外，也能读取 TIFF（`.tif`、`.tiff`）。

## 工作区上的尺寸标注、标尺和节点菜单

* **尺寸标注**（**Dimensions**，工作区上方工具条中 **刀具路径**（**Toolpaths**）旁边的按钮）像工程图那样显示图纸：整体及每个轮廓（形状的外轮廓和各个孔分别标注）的宽度和高度，以及圆形的直径，相同的只标注一次（**4 × Ø 6**）。它不会改变图纸中的任何内容。
* **标尺 (M)** 可以捕捉形状的节点（以方块标记）、线段的中点（以菱形标记）或圆、椭圆的圆心（以圆圈标记）。单击圆时显示从圆心到单击点的半径以及直径；单击椭圆时显示两个半径以及到单击点的半径；单击曲线时显示其长度，如果该曲线是圆弧，还会显示从圆心画到单击点的半径及其长度。
* **节点编辑**：在节点或线段上右键单击会打开节点栏的菜单；**平滑**（**Smooth**）的快捷键是 **G**，**倒圆 (R)** 的半径显示在其按钮之后。

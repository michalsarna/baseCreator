# 限制

* **没有机器**：没有设备、连接、G-code、作业预览或摄像头。这些功能请使用 LightCreator、MillCreator 或 PenCreator。
* **只支持平面图纸。** 3D 模型和浮雕 STL 在 MillCreator 中。
* **图片不会被导出。** SVG、PLT 和 DXF 只包含轮廓；请先描摹图片。
* **UGS 设计**导入的是位于各图层上的形状；进给速度和深度会被忽略。
* **PLT 文件**只经过针对其文本的测试，尚未在真实绘图仪或其他程序中检验。
* **没有使用付费开发者账户签名**：macOS 和 Windows 在第一次运行时会发出警告。参见[安装](Installation-ZH)。
* **页面设置**（**Page setup**）没有出血或打印设置，程序也不能打印。

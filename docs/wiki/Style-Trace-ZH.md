# 风格描摹

**排列 → 风格描摹…**（**Arrange → Style trace…**）用 21 种风格之一，以线条重绘所选图片，结果可以直接导出、打印或在其他程序中打开：波浪线、螺旋、波浪、半色调圆、排线、点画、一笔画、流线、素描等等。它也位于图片的右键菜单中，以及 **属性**（**Properties**）的 **图像**（**Image**）部分。它在 LightCreator、MillCreator、PenCreator 和 BaseCreator 中的用法完全相同。

![流线风格下的“风格描摹”窗口](https://raw.githubusercontent.com/michalsarna/LightCreator/main/docs/screenshots/14b-style-trace.png)

## 操作步骤

1. 选择一张图片，然后选择 **风格描摹…**。
2. 选择 **风格**（**Style**）；下方的一行文字说明它会画出什么。有些风格有 **类型**（**Kind**，例如点画可选点、短划线或三角形）。
3. 调整风格的设置。预览显示的线条与将放到图纸上的完全一致；它在后台计算，因此窗口不会卡住（在新线条准备好之前，旧线条保持灰色）。按钮下方的一行文字说明有多少条线以及它们的总长度。
4. **色调**（**Tone**）：**黑点**（**Black point**）和 **白点**（**White point**）截去最暗和最亮的灰度，**伽马**（**Gamma**）使中间调变亮（大于 1）或变暗，**描摹亮区**（**Trace the light areas**）交换暗部和亮部。
5. **放到图层**（**Put on the layer**）：程序会选择第一个没有形状的图层（不是图片自己所在的图层）。你可以从列表中选择其他图层。
6. **之后删除图像**（**Delete the image afterwards**）在生成线条后删除图片。
7. **描摹**（**Trace**）把线条作为一个形状放到图纸上，位置与图片相同（随图片一起移动、旋转和缩放）。**编辑 → 撤销**（**Edit → Undo**）可以撤回。

使用随机性的风格（点画、流线、素描、涂鸦、方块、针线、Truchet 拼贴）有一个 **随机图案**（**Random pattern**）编号：相同的编号每次都会得到相同的线条，**换一个**（**Another**）会尝试另一个编号。

## 风格

| 风格 | 绘制内容 | 设置 |
|---|---|---|
| **波浪线**（**Squiggle**） | 一行行的线条，图片越暗的地方波动越快、越高。 | **线条间距**（**Spacing of the lines**）、**波高**（**Wave height**）、**每毫米波数**（**Waves per mm**）、**角度**（**Angle**）；类型：从边到边的行，或 **在白色处抬笔**（**Lift the pen over white**）。 |
| **锯齿**（**Sawtooth**） | 同样的行，但为锯齿形。 | 同波浪线。 |
| **弹簧**（**Springs**） | 一行行像拉伸弹簧般的环圈，越暗的地方越大。 | 同波浪线。 |
| **螺旋**（**Spiral**） | 从中心出发的一条螺旋线，在阴影处摆动更大（其他程序中的 *频率线*（*Frequency lines*））。 | **圈间距**（**Spacing of the turns**）、**波高**、**每毫米波数**；类型：波浪或锯齿。 |
| **波浪**（**Waves**） | 被暗度抬高的行，像从侧面看到的地形；前面的行会遮住后面的内容。 | **线条间距**、**波浪高度**（**Height of the waves**）；类型：遮住后面的内容，或完整绘制每一行。 |
| **半色调圆**（**Halftone circles**） | 由圆组成的网格，圆的大小随色调变化，就像印刷照片那样。 | **单元格大小**（**Cell size**）、**最大圆**（**Largest circle**）、**圆环间距**（**Spacing of the rings**）、**角度**；类型：圆、圆环（以圆环填充）或螺旋。 |
| **蚀刻**（**Etching**） | 分层排线，就像古老的版画：每增加一级暗色调，就添加另一个方向的线条。 | **线条间距**、**色调级数**（**Tone levels**，1 到 6）、**角度**；类型：直线或波浪线。 |
| **方块**（**Squares**） | 由嵌套方块组成的网格，越暗的地方方块越多。 | **单元格大小**、**每个单元格最多方块数**（**Most squares in a cell**）、**抖动**（**Shake**，随机旋转）、**角度**。 |
| **针线**（**Needles**） | 网格上的短笔画，越暗的地方越长。 | **单元格大小**、**笔画长度**（**Stroke length**）、**角度**；类型：沿着形状、按角度或随机。 |
| **Truchet 拼贴**（**Truchet tiles**） | 随机旋转的四分之一圆拼贴，越暗的地方弧线越多。 | **拼贴大小**（**Tile size**）、**每块拼贴最多弧线数**（**Most arcs in a tile**）。 |
| **等值线**（**Contour lines**） | 亮度相等的线，就像地图上的等高线。 | **平滑**（**Smoothing**）、**色调级数**（2 到 40）。 |
| **希尔伯特曲线**（**Hilbert curve**） | 一条空间填充曲线，越暗的地方转折越细密。 | **最小步长**（**Smallest step**）、**色调级数**；类型：一条线，或 **在白色处抬笔**。 |
| **点画**（**Stippling**） | 按色调分布的点（加权 Voronoi 点画）：阴影处密集，亮处稀疏。 | **点数**（**Number of dots**）、**点大小**（**Dot size**）；类型：点、按色调变化的圆、短划线或三角形。 |
| **一笔画 (TSP)**（**One line (TSP)**） | 把点画的点连成一条不自相交的线，绘制时无需抬笔。 | **点数**（最多 15 000）。 |
| **三角形与单元**（**Triangles and cells**） | 在按色调分布的点上生成三角网（Delaunay），或围绕各点的单元（Voronoi）。 | **点数**；类型：三角形或单元。 |
| **线稿**（**Line art**） | 只把图片的边缘画成线条。 | **最小细节**（**Smallest detail**）、**边缘灵敏度**（**Edge sensitivity**）、**最短线条**（**Shortest line**）；类型：边缘，或边缘加暗区。 |
| **流线**（**Flow lines**） | 沿形状流动的长线，越暗的地方越密。 | **最小间隙**（**Smallest gap**，在最暗处）、**最大间隙**（**Largest gap**，在最亮处）、**曲线大小**（**Size of the curves**）、**角度**；类型：沿着形状或随机流场。 |
| **素描**（**Sketch**） | 大量短直笔画铺在图片最暗的地方，就像铅笔素描。 | **笔画长度**、**笔画数**（**Number of strokes**）、**单笔墨量**（**Ink of one stroke**，一笔吸收多少暗度）；类型：分开的笔画或成链的笔画。 |
| **涂鸦**（**Scribble**） | 一条蜿蜒的环圈线，把暗部涂满。 | **环圈大小**（**Loop size**）、**线条长度**（**Length of the line**，米）、**单次墨量**（**Ink of one pass**）。 |
| **V 雕**（**V-carve**） | 按角度排列的线条，每条线的宽度随其经过处图片的暗度变化：亮处细，阴影处宽，正如 V 形刀切得越深就越宽。每条线被切成若干段，每段的亮度决定其宽度；每条线是一个闭合轮廓。变体：**平滑**（**Smooth**，穿过各段的平滑曲线）或 **棱角**（**Angular**，各段之间为直线）。 | **线条宽度**（**Width of the lines**，也是最宽线条的宽度）、**分段长度**（**Length of the pieces**）、**最细线条**（**Thinnest line**，在白色处所占宽度的比例；0：该处没有线条）、**角度**。 |
| **几何多边形**（**Geometric polygons**） | 把图片的暗色形状分割成多边形（三角形和四边形），图片有边缘的地方更多，多边形之间以及外轮廓周围留有间隙：一幅几何（低多边形）图片，可作为墙面装饰或模板。外轮廓沿形状走，多边形被裁切到外轮廓。也可以通过 **排列 → 几何多边形…**（**Arrange → Geometric polygons…**）使用。变体：**三角形和四边形**（**Triangles and quadrangles**）、**三角形**（**Triangles**）；换一个 **种子**（**seed**）会得到不同的多边形；色调设置（黑点）决定什么是暗色形状。 | **多边形间隙**（**Gap between the polygons**，0：每条边为一条线）、**多边形数量**（**Number of polygons**）、**跟随边缘**（**Follow the edges**，0：均匀，1：只按边缘）。 |

## 须知

* 设置以图片的毫米为单位，因此图片越大，线条越多，而不是越粗。线条间距应大于笔、激光光斑或刀具的宽度。
* 一个点就是一个闭合的小圆，因此它像其他线条一样被绘制、烧刻或雕刻。
* **一笔画 (TSP)**、**螺旋** 和 **希尔伯特曲线** 以一次长移动绘制；其他风格会排列顺序，使线条之间的移动尽量短。
* 设置过于精细会产生大量的点：按钮下方的一行文字会在绘图将变慢时发出警告，结果最多为两百万个点。
* 当风格需要更高对比度时，先调整图片（**排列 → 调整图像…**（**Arrange → Adjust image…**）：亮度、对比度、色阶）。

## 图片风格面板

选中图片时，侧边面板中有一个 **图片风格**（**Picture styles**）标签页（选中图片时自动打开，没有选中图片时消失）。其顶部有一个与面板等宽的橙色按钮，用于打开 **编辑图像…**（**Edit image…**，即照片编辑器），下面一个按钮打开 **描摹图像…**（**Trace image…**）；再往下，像图库一样列出每种风格的小图（以该风格绘制的一个三角形）。单击其中一个会打开 **风格描摹**，并已选中该风格。

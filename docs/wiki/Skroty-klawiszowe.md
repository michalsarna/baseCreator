# Skróty klawiszowe

Ctrl to Cmd na Macu. Klawisze działają w edytorze, nie na ekranie startowym, i żaden nie jest przechwytywany, gdy klawiaturę ma pole tekstowe.

## Klawisze menu

| Klawisz | Polecenie | Klawisz | Polecenie |
|---|---|---|---|
| Ctrl+N | **Nowy** | Ctrl+D | **Powiel** |
| Ctrl+O | **Otwórz…** | Delete lub Backspace | **Usuń** |
| Ctrl+S | **Zapisz** | Ctrl+A | **Zaznacz wszystko** |
| Ctrl+Shift+S | **Zapisz jako…** | Ctrl+G | **Grupuj** |
| Ctrl+I | **Importuj SVG…** | Ctrl+Shift+G | **Rozgrupuj** |
| Ctrl+Q | **Zakończ** | Ctrl+L | **Zablokuj** |
| Ctrl+Z | **Cofnij** | Ctrl+Shift+L | **Odblokuj** |
| Ctrl+Y lub Ctrl+Shift+Z | **Ponów** | Ctrl++ (Ctrl+=) | **Powiększ** |
| Ctrl+C | **Kopiuj** | Ctrl+- | **Pomniejsz** |
| Ctrl+V | **Wklej** | Ctrl+Shift+0 | **Dopasuj stół do okna** |
| | | Ctrl+Shift+9 | **Dopasuj do wszystkich obiektów** |

## Karty rysunków

| Klawisz | Co robi |
|---|---|
| Ctrl+1 … Ctrl+9, Ctrl+0 | Pokazuje 1. … 9. kartę, Ctrl+0 dziesiątą. |
| Ctrl+W | Zamyka pokazywany rysunek; przy niezapisanej pracy najpierw pyta. |

## Narzędzia

| Klawisz | Narzędzie | Klawisz | Narzędzie |
|---|---|---|---|
| V | **Zaznaczanie (V)** | I | **Spirala (I)** |
| N | **Edycja węzłów (N)** | L | **Linia (L)** |
| R | **Prostokąt (R)** | P | **Linia łamana / pióro (P)** |
| E | **Elipsa (E)** | T | **Tekst (T)** |
| Y | **Trójkąt (Y)** | H | **Przesuwanie widoku (H)** |
| S | **Gwiazda (S)** | Z | **Powiększ (Z)** |
| G | **Wielokąt (G)** | X | **Pomniejsz (X)** |
| K | **Serce (K)** | | |

| Klawisz | Co robi |
|---|---|
| Esc | Czyści zaznaczenie (i rysowaną łamaną). |
| Dwa razy Esc (w ciągu pół sekundy) | Powrót do **Zaznaczanie (V)**. |
| Enter | Kończy rysowaną łamaną. |

## Mysz z klawiszami

| Czynność | Co robi |
|---|---|
| Kółko (lub szczypanie) na obszarze roboczym | Powiększa wokół wskaźnika. |
| Przeciąganie środkowym przyciskiem | Przesuwa widok. |
| Shift+klik lub Ctrl+klik | Dodaje kształt do zaznaczenia lub go z niego usuwa. |
| Shift przy rysowaniu kształtu | Utrzymuje równą szerokość i wysokość. |
| Przeciąganie uchwytu narożnika | Zachowuje proporcje; z Shiftem zmieniają się swobodnie. |
| Shift przy obracaniu | Obraca co 15°. |
| Prawy klik lub dwuklik z **Linia łamana / pióro (P)** | Kończy łamaną; klik przy pierwszym punkcie ją zamyka. |
| Prawy klik na kształcie | Menu kształtu. |
| Środkowy klik na karcie | Zamyka kartę. |
| Dwuklik na linii między panelami | Wyrównuje rozmiar paneli. |

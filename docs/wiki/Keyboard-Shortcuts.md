# Keyboard Shortcuts

Ctrl is Cmd on a Mac. The keys work in the editor, not on the start screen, and none of them is taken while a text field has the keyboard.

## Keys of the menus

| Key | Command | Key | Command |
|---|---|---|---|
| Ctrl+N | **New** | Ctrl+D | **Duplicate** |
| Ctrl+O | **Open…** | Delete or Backspace | **Delete** |
| Ctrl+S | **Save** | Ctrl+A | **Select all** |
| Ctrl+Shift+S | **Save as…** | Ctrl+G | **Group** |
| Ctrl+I | **Import SVG…** | Ctrl+Shift+G | **Ungroup** |
| Ctrl+Q | **Quit** | Ctrl+L | **Lock** |
| Ctrl+Z | **Undo** | Ctrl+Shift+L | **Unlock** |
| Ctrl+Y or Ctrl+Shift+Z | **Redo** | Ctrl++ (Ctrl+=) | **Zoom in** |
| Ctrl+C | **Copy** | Ctrl+- | **Zoom out** |
| Ctrl+V | **Paste** | Ctrl+Shift+0 | **Fit bed to window** |
| | | Ctrl+Shift+9 | **Fit all objects** |

## Tabs of drawings

| Key | What it does |
|---|---|
| Ctrl+1 … Ctrl+9, Ctrl+0 | Shows the 1st … 9th tab, Ctrl+0 the 10th. |
| Ctrl+W | Closes the drawing that is shown; with unsaved work you are asked first. |

## Tools

| Key | Tool | Key | Tool |
|---|---|---|---|
| V | **Select (V)** | I | **Spiral (I)** |
| N | **Node edit (N)** | L | **Line (L)** |
| R | **Rectangle (R)** | P | **Polyline / pen (P)** |
| E | **Ellipse (E)** | T | **Text (T)** |
| Y | **Triangle (Y)** | H | **Pan (H)** |
| S | **Star (S)** | Z | **Zoom in (Z)** |
| G | **Polygon (G)** | X | **Zoom out (X)** |
| K | **Heart (K)** | | |

| Key | What it does |
|---|---|
| Esc | Clears the selection (and a polyline being drawn). |
| Esc twice (within half a second) | Back to **Select (V)**. |
| Space (hold) | Pan with any tool; release it to go back to the tool you had. |
| Arrow keys | Move the selection by 1 mm; **Shift** + arrow = 10 mm. |
| G, I | Polygon and spiral: a small window sets the number of sides or turns, also of the shape drawn last. |
| Enter | Ends the polyline being drawn. |

## Mouse with keys

| Action | What it does |
|---|---|
| Wheel (or pinch) on the work area | Zooms about the pointer. |
| Middle button drag | Pans the view. |
| Shift+click or Ctrl+click | Adds a shape to the selection, or takes it out. |
| Shift while drawing a shape | Keeps the width and the height equal. |
| Dragging a corner handle | Keeps the proportions; with Shift they change freely. |
| Shift while turning | Turns in steps of 15°. |
| Right click, or double click, with **Polyline / pen (P)** | Ends the polyline; a click near the first point closes it. |
| Right click on a shape | The menu of the shape. |
| Middle click on a tab | Closes the tab. |
| Double click on the line between panes | Makes the panes the same size. |

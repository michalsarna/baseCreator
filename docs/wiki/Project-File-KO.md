# 프로젝트 파일

BaseCreator는 LightCreator, MillCreator, PenCreator도 저장하는 프로젝트 파일 형식인 **`.cre`** 파일로 저장합니다. 그림, 설명, 그리고 **프로그램마다 하나의 섹션**(`draw`, `laser`, `mill`, `pen`)이 담긴 하나의 JSON 파일입니다. 각 프로그램은 자신의 섹션만 쓰고 다른 섹션은 그대로 두므로, 프로젝트가 프로그램 사이를 오가도 잃는 것이 없습니다.

`draw` 섹션에는 페이지와 64개의 레이어(이름, 색, 표시 여부)가 들어 있습니다.

* 여기서 만든 프로젝트는 다른 프로그램에서 그림과 설명과 함께 열립니다. 그 프로그램들은 `draw`를 유지합니다.
* 그곳에서 만든 프로젝트는 여기서 그림과 함께 열립니다. 기본 레이어와 마지막 새 그림의 페이지가 주어지며, 그림이 들어가지 않으면 페이지가 더 크게 만들어집니다. 기계 설정은 여기서 저장한 뒤에도 파일에 남습니다.
* `draw`의 형식이 더 새로운 파일은 거부되며, 프로그램을 업데이트하라는 안내가 나옵니다.

## 만든 사람과 기여자

파일에는 누가 프로젝트를 만들었고 누가 작업했는지도 `authorship` 블록에 기록됩니다.

* **만든 사람**(**Creator**): 프로젝트를 처음 저장한 사람.
* **기여자**(**Contributors**): 그 밖에 프로젝트를 저장한 모든 사람. 각 사람은 한 번만 추가됩니다. 만든 사람은 이름, 이메일, 기타 항목을 모두 저장하고, 기여자(와 편집 기록)는 이름과 이메일만, 이메일이 만든 사람과 같으면 이름만 저장합니다.
* **편집**(**Edits**): 직접 저장한 기록(최근 200개). 같은 사람과 같은 프로그램에 대해서는 1분에 최대 한 번입니다. 자동 저장은 편집 기록을 추가하지 않습니다.

각 항목에는 이름, 이메일, 자유 텍스트(회사, 웹사이트…), 시각(UTC), 그리고 프로그램과 그 버전이 있습니다. 이 값들은 **설정 → 프로그램 옵션**(**Settings → Program options**)의 **작성자**(**Author**) 부분에서 **이름**(**Your name**), **이메일**(**Email**), **기타**(**Other**)로 설정합니다. 공유 폴더의 파일 하나(`author.json`)에 보관되므로 BaseCreator, LightCreator, MillCreator, PenCreator에서 모두 같습니다. 이름이나 이메일이 없으면 저장할 때 시각과 프로그램은 기록되지만 사람은 기록되지 않습니다.

**파일 → 프로젝트 정보…**(**File → Project information…**)는 파일(이름, 폴더, 크기, 만든 시각과 변경한 시각), 작성자(프로젝트를 만든 시각, 만든 사람과 그 이메일, 기타 항목을 각각 한 줄씩, 기여자와 그 이메일), 그리고 편집 기록 표(시각, 사람, 프로그램)를 보여 줍니다.

파일이 있는 프로젝트는 변경 후 약 20초가 지나면 저절로 그 파일에 저장됩니다. [설정과 파일](Settings-and-Files-KO)을 참고하십시오.

## 비밀번호 보호

> ⚠️ 이 절은 영어판을 기계 번역한 것입니다.

프로젝트는 비밀번호로 보호할 수 있습니다: LightCreator, MillCreator, PenCreator의 **프로젝트 설정…**(**Project setup…**)과 BaseCreator의 **파일 → 페이지 설정…**(**File → Page setup…**)에 있는 **보호**(**Protection**) 부분에서 설정합니다.

* **소유자 비밀번호**: 모든 것(편집, 복사, 내보내기, 보호 변경 또는 해제).
* **열기 비밀번호**(선택): 프로젝트를 열고, 보고, G-code로 만들고, 기계에서 실행할 수 있으며, 재료와 레이어 설정(속도, 출력, 패스, 깊이, 비트, 펜)을 바꿀 수 있지만, 도면을 편집하거나 복사하거나 도면 형식(SVG, DXF, Illustrator, LightBurn …)으로 내보내거나 인쇄할 수는 없습니다. 이때 내장 웹 페이지는 도면을 보여 주지 않습니다.
* 소유자 비밀번호만 있으면 다른 사람은 파일을 열 수 없습니다. 비밀번호 없이는 파일을 전혀 읽을 수 없고, **잊은 비밀번호는 되찾을 수 없습니다**.

파일은 `protected_cre` 키를 가진 JSON 텍스트로 남습니다. 그 안의 프로젝트는 무작위 256비트 키로 **XChaCha20-Poly1305** 암호화되며, 이 키는 비밀번호마다 한 번씩, **Argon2id**(64 MiB, 3회, 개별 솔트)로 비밀번호에서 만든 키로 감싸져 저장됩니다. 저장할 때마다 새 nonce를 쓰며, 바뀐 파일은 열리지 않습니다. 비밀번호는 8자 이상이어야 하고, 열기 비밀번호는 소유자 비밀번호와 달라야 합니다.

열기 비밀번호가 금지하는 것은 PDF의 소유자 비밀번호처럼 프로그램이 지킵니다: 그것을 아는 사람은 원칙적으로 다른 도구로 프로젝트를 해독할 수 있습니다. 소유자 비밀번호는 자신만 가지고 있으세요.

# 键盘快捷键

在 Mac 上，Ctrl 为 Cmd。这些快捷键在编辑器中有效，在启动界面上无效；当文本字段获得键盘焦点时，所有快捷键都不会被占用。

## 菜单快捷键

| 按键 | 命令 | 按键 | 命令 |
|---|---|---|---|
| Ctrl+N | **新建**（**New**） | Ctrl+D | **再制**（**Duplicate**） |
| Ctrl+O | **打开…**（**Open…**） | Delete 或 Backspace | **删除**（**Delete**） |
| Ctrl+S | **保存**（**Save**） | Ctrl+A | **全选**（**Select all**） |
| Ctrl+Shift+S | **另存为…**（**Save as…**） | Ctrl+G | **编组**（**Group**） |
| Ctrl+I | **导入 SVG…**（**Import SVG…**） | Ctrl+Shift+G | **取消编组**（**Ungroup**） |
| Ctrl+Q | **退出**（**Quit**） | Ctrl+L | **锁定**（**Lock**） |
| Ctrl+Z | **撤销**（**Undo**） | Ctrl+Shift+L | **解锁**（**Unlock**） |
| Ctrl+Y 或 Ctrl+Shift+Z | **重做**（**Redo**） | Ctrl++（Ctrl+=） | **放大**（**Zoom in**） |
| Ctrl+C | **复制**（**Copy**） | Ctrl+- | **缩小**（**Zoom out**） |
| Ctrl+V | **粘贴**（**Paste**） | Ctrl+Shift+0 | **工作台适合窗口**（**Fit bed to window**） |
| | | Ctrl+Shift+9 | **显示全部对象**（**Fit all objects**） |

## 图纸标签页

| 按键 | 作用 |
|---|---|
| Ctrl+1 … Ctrl+9、Ctrl+0 | 显示第 1 个……第 9 个标签页，Ctrl+0 显示第 10 个。 |
| Ctrl+W | 关闭当前显示的图纸；有未保存的内容时会先询问。 |

## 工具

| 按键 | 工具 | 按键 | 工具 |
|---|---|---|---|
| V | **选择 (V)**（**Select (V)**） | I | **螺旋 (I)**（**Spiral (I)**） |
| N | **节点编辑 (N)**（**Node edit (N)**） | L | **直线 (L)**（**Line (L)**） |
| R | **矩形 (R)**（**Rectangle (R)**） | P | **折线 / 钢笔 (P)**（**Polyline / pen (P)**） |
| E | **椭圆 (E)**（**Ellipse (E)**） | T | **文字 (T)**（**Text (T)**） |
| Y | **三角形 (Y)**（**Triangle (Y)**） | H | **平移 (H)**（**Pan (H)**） |
| S | **星形 (S)**（**Star (S)**） | Z | **放大 (Z)**（**Zoom in (Z)**） |
| G | **多边形 (G)**（**Polygon (G)**） | X | **缩小 (X)**（**Zoom out (X)**） |
| K | **心形 (K)**（**Heart (K)**） | M | **标尺 (M)**（**Ruler (M)**） |

| 按键 | 作用 |
|---|---|
| Esc | 清除选择（以及正在绘制的折线）。 |
| 连按两次 Esc（半秒内） | 返回 **选择 (V)**。 |
| 空格（按住） | 使用任何工具时平移视图；松开后返回原来的工具。 |
| 方向键 | 将所选内容移动 1 mm；**Shift** + 方向键 = 10 mm。 |
| G、I | 多边形和螺旋：弹出一个小窗口，设置边数或圈数，也作用于最近绘制的形状。 |
| Enter | 结束正在绘制的折线。 |

## 鼠标与按键配合

| 操作 | 作用 |
|---|---|
| 在工作区上滚动滚轮（或双指捏合） | 以指针为中心缩放。 |
| 按住中键或右键拖动 | 平移视图，在工作区上和工作区旁都可以（不移动的右键单击会打开菜单）。 |
| Shift+单击或 Ctrl+单击 | 把形状加入选择，或从选择中移除。 |
| 绘制形状时按住 Shift | 保持宽度和高度相等。 |
| 拖动角上的控制柄 | 保持比例；按住 Shift 时可自由改变。 |
| 旋转时按住 Shift | 以 15° 为步长旋转。 |
| 使用 **折线 / 钢笔 (P)** 时右键单击或双击 | 结束折线；在第一个点附近单击会闭合折线。 |
| 在形状上右键单击 | 打开形状的菜单。 |
| 在标签页上单击中键 | 关闭标签页。 |
| 双击窗格之间的分隔线 | 使各窗格大小相同。 |

# 支持本项目

BaseCreator 是免费的开源软件。如果它对你有用，你可以请作者喝杯咖啡：**<https://buymeacoffee.com/michalsarna>**

捐款不是必需的。你还可以通过以下方式提供帮助：
* 在 [Issues](https://github.com/michalsarna/baseCreator/issues) 中报告错误和提出想法，
* 试用程序并分享结果，
* 改进翻译，
* 为项目点星并告诉其他人。

谢谢！

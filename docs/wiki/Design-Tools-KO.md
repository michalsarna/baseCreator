# 디자인 도구

BaseCreator는 LightCreator, MillCreator, PenCreator와 같은 도구로 도형을 편집합니다. 키는 [키보드 단축키](Keyboard-Shortcuts-KO)에, 메뉴는 [메뉴](Menus-KO)에 있습니다.

## 그리기

왼쪽 팔레트에는 **선택 (V)**(**Select (V)**), **노드 편집 (N)**(**Node edit (N)**), **사각형 (R)**(**Rectangle (R)**), **타원 (E)**(**Ellipse (E)**), **삼각형 (Y)**(**Triangle (Y)**), **별 (S)**(**Star (S)**), **다각형 (G)**(**Polygon (G)**), **하트 (K)**(**Heart (K)**), **나선 (I)**(**Spiral (I)**), **선 (L)**(**Line (L)**), **폴리라인 / 펜 (P)**(**Polyline / pen (P)**), **텍스트 (T)**(**Text (T)**), **이동 (H)**(**Pan (H)**), **확대 (Z)**(**Zoom in (Z)**), **축소 (X)**(**Zoom out (X)**), **자 (M)**(**Ruler (M)**)가 있습니다. 객체를 삽입하는 도구는 **삽입**(**Insert**) 메뉴에도 있으며, **도형 생성…**(**Generate shape…**, 플러그인의 생성기)과 **온라인 클립아트…**(**Online clipart…**)도 함께 있습니다.

## 텍스트

**텍스트 (T)** 도구를 고르고 페이지를 클릭하면 텍스트가 나타나고, 입력란이 있는 **속성**(**Properties**) 탭이 열립니다. 여기서 글꼴, 크기, 굵게와 기울임꼴, 자간과 행간, 정렬을 설정합니다. **곡선으로 변환**(**Convert to curves**)은 텍스트를 노드를 편집할 수 있는 도형으로 바꿉니다. 새 텍스트는 마지막으로 변경한 텍스트의 설정을 이어받습니다.

## 편집

* 도형 위에서 **마우스 오른쪽 버튼**을 누르면 메뉴가 열립니다: 복사, 그룹화, 잠금, 뒤집기와 90° 회전, **정렬**(**Arrange**) 및 **도형 연산**(**Shape operations**) 하위 메뉴, 그리고 그림에 대해서는 **이미지 조정…**(**Adjust image…**)과 **이미지 트레이스…**(**Trace image…**). 선택한 것에 맞지 않는 항목은 회색으로 표시됩니다.
* **Esc를 두 번**(0.5초 안에) 누르면 **선택 (V)** 도구로 돌아갑니다.
* **실행 취소**(**Undo**)는 그림마다 최대 100단계를 보관합니다.

## 도형 연산

**합치기**(**Union**), **교차**(**Intersection**), **빼기**(**Subtract**), **배타적 논리합**(**Exclusive or**)은 닫힌 도형을 결합합니다. **도형 오프셋…**(**Offset shape…**)은 더 크거나 작은 윤곽선을 만들고, **모서리 둥글게…**(**Round corners…**)는 모서리를 둥글게 하며, **곡선으로 변환**은 직선 대신 곡선을 넣고, **경로로 변환**(**Convert to path**)은 사각형이나 별을 경로로 만들어 노드를 편집할 수 있게 합니다.

## 배치와 복사

다음은 모두 **정렬**(**Arrange**) 메뉴에 있습니다.

* **경로 자동 연결…**(**Auto-join paths…**)은 끝점이 허용 오차보다 가까운 열린 경로를 연결합니다. **허용 오차로 경로 닫기…**(**Close path with tolerance…**)는 양 끝점이 그만큼 가까운 경로를 닫습니다. **도그본 / T본 모서리…**(**Dogbone / T-bone corners…**)는 밀링할 도형을 위해 뾰족한 모서리에 홈을 추가합니다.
* **격자 배열…**(**Grid array…**)은 행과 열로 복사합니다. **원형 배열…**(**Circular array…**)은 선택 영역의 중심 둘레에 복사본을 배치합니다. 복사본은 최대 2000개까지 만들어집니다.
* **경로를 따라 복사…**(**Copy along path…**): 도형을 선택한 뒤 경로를 **마지막에** 선택합니다. **경로 위 텍스트…**(**Text on path…**): 텍스트를 선택한 뒤 경로를 마지막에 선택합니다. 그 후에는 텍스트가 아니라 윤곽선이 됩니다.
* **도형으로 자르기…**(**Trim by shape…**): 선을 선택한 뒤 닫힌 도형을 **마지막에** 선택합니다. **중복 제거**(**Remove duplicates**)는 같은 레이어에서 윤곽선이 같은 도형을 삭제합니다. **분해**(**Break apart**)는 윤곽선마다 하나의 도형을 만듭니다. **단순화…**(**Simplify…**)는 선에서 허용 오차 이내에 있는 점을 제거합니다.
* **일련번호 텍스트…**(**Serial text…**): 텍스트를 복사하면서 `{n}`을 하나씩 늘리거나, CSV 파일을 사용하면 행마다 한 번씩 복사합니다. **바코드 / QR 코드…**(**Barcode / QR code…**)는 사용 중인 레이어에 코드를 윤곽선으로 배치합니다.
* **도형 배치(네스팅)…**(**Nest shapes…**)는 선택한 도형을 윤곽선이 아니라 경계 상자를 기준으로 행에 채워 넣습니다. **측정…**(**Measure…**)은 선택한 것의 크기, 위치, 면적, 길이를 보여 주고, 도형이 두 개이면 둘 사이의 거리도 보여 줍니다.

## 그림

**파일 → 가져오기 → 이미지 가져오기…**(**File → Import → Import image…**)를 선택하거나 그림을 창에 끌어다 놓으면 가져오기 대화 상자가 열립니다. **이미지 조정…** 명령은 페이지 위의 그림을 바꾸고, **이미지 트레이스…** 명령은 어둡거나 밝은 영역을 윤곽선으로 바꿉니다. 그림에는 자체 윤곽선이 없으므로 트레이스하기 전까지는 내보내기에서 제외됩니다.

**이미지 편집…**(**Edit image…**, 정렬 메뉴, 마우스 오른쪽 버튼 메뉴, **그림 스타일**(**Picture styles**) 탭의 주황색 버튼에 있음)은 선택한 그림의 사진 편집기를 엽니다: **브러시**, **지우개**(손대지 않은 재료처럼 흰색으로 칠합니다), **복제 도장**(Ctrl+클릭, Mac에서는 Cmd+클릭으로 복사할 위치를 지정한 뒤 칠합니다), 그리고 클릭한 곳 주변의 비슷한 회색 영역을 채우는 **채우기**. 색은 회색만 사용합니다. 브러시의 크기, 경도, 불투명도와 채우기의 허용 오차는 왼쪽 열에서 설정하며, 실행 취소와 다시 실행으로 앞뒤로 이동할 수 있습니다. 휠은 확대/축소하고, 오른쪽 또는 가운데 버튼은 그림을 이동합니다. **적용**(**Apply**)을 누르기 전까지 그림에는 아무것도 바뀌지 않습니다.

**이미지로 변환…**(**Convert to image…**, 도형이 선택되어 있고 그중에 그림이 없을 때)은 도형을 하나의 그림으로 바꿉니다. 창에는 미리 보기, 해상도(DPI)와 그림 크기, 닫힌 도형을 채울지 여부, 선 두께가 표시됩니다. **이후 객체 삭제**(**Delete the objects afterwards**)는 그림이 만들어지면 도형을 제거하고, **객체 숨기기**(**Hide the objects**)는 미리 보기에서만 윤곽선을 뺍니다. 그림은 도형이 있던 자리에, 다른 도형이 없는 레이어(도형을 삭제하는 경우 도형의 레이어, 그림이 있는 레이어, 또는 빈 레이어)에 배치됩니다.

**이미지 트레이스**와 **스타일 트레이스**(**Style trace**) 창의 **그림 숨기기**(**Hide the picture**)는 미리 보기에서 그림 없이 결과만 보여 줍니다.

**정렬 → 스타일 트레이스…**(**Arrange → Style trace…**)는 그림을 21가지 스타일(꼬불꼬불한 선, 나선, 점묘, 해칭, 흐름선, 하나의 연속선…) 중 하나의 선으로 다시 그립니다: [스타일 트레이스](Style-Trace-KO)를 참고하십시오.

**보기 → 배경 그림…**(**View → Background picture…**)은 그림 아래에 사진이나 스캔 이미지를 깔아 그 위에 따라 그릴 수 있게 합니다. 프로젝트와 함께 저장됩니다.

## 클립아트 갤러리

**클립아트**(**Clipart**) 탭에는 다른 프로그램과 공유하는 갤러리에 미리 만들어진 그림이 있습니다. **삽입 → 온라인 클립아트…**(**Insert → Online clipart…**)는 인터넷에서 무료 그림을 검색합니다.

## 오른쪽 패널

탭은 **속성**(**Properties**), **레이어**(**Layers**), **클립아트**(**Clipart**), **설명**(**Description**)입니다. [창과 탭](Panes-and-Tabs-KO#오른쪽-패널)을 참고하십시오.

## 자, 선택, 노드 막대

* **자 (M):** 팔레트에서 **축소 (X)** 다음에 있는 도구입니다. 한 점에서 다른 점으로 끌거나 두 점을 클릭하면, 그림 위에 선이 나타나 길이, ΔX, ΔY, 각도를 프로그램 단위로 보여 줍니다. 도형의 노드 근처의 점은 노드 자체에 맞춰집니다(그렇지 않으면 스냅이 켜져 있을 때 그리드에 맞춰집니다). 도형의 직선 구간(사각형의 변, 선)을 클릭하면 그 구간을 측정합니다. 측정 결과는 다음 측정, **Esc** 또는 다른 도구를 고를 때까지 남아 있으며, 그림은 전혀 바뀌지 않습니다.
* **도구를 든 상태에서 오른쪽 클릭**(도형, 펜, 노드 도구, 자…)은 **Esc**를 두 번 누른 것과 같습니다: 아무것도 선택되지 않은 채 **선택 (V)** 도구로 돌아갑니다. 펜으로 그리던 선은 먼저 마무리됩니다. 선택 도구에서는 오른쪽 클릭이 이전처럼 컨텍스트 메뉴를 엽니다.
* **여러 객체를 선택한 경우:** 전체 선택 영역의 테두리 외에, 각 객체에도 얇은 점선 테두리가 표시됩니다.
* **노드 막대**는 이름 뒤에 키를 표시합니다: **모서리 (C)**(**Corner (C)**), **직선으로 (L)**(**To line (L)**), **곡선으로 (S)**(**To curve (S)**), **노드 추가 (I)**(**Add node (I)**), **노드 삭제 (D)**(**Delete node (D)**), **둥글게 (R)**(**Round (R)**), **끊기 (B)**(**Break (B)**). **열기 / 닫기**(**Open / close**)는 없어졌습니다. **끊기 (B)** 명령으로 경로를 열고, 경로의 한쪽 끝을 다른 쪽 끝 위에 놓으면 경로가 닫힙니다.
* **만들지 않는 레이어**(출력이 꺼진 레이어)의 객체는 작업 영역 쪽으로 흐리게 표시됩니다.

* **그림:** PNG, JPEG, BMP, GIF, WebP와 마찬가지로 TIFF(`.tif`, `.tiff`)도 읽습니다.

## 작업 영역의 치수, 자, 노드 메뉴

* **치수**(**Dimensions**, 작업 영역 위 막대의 **툴패스**(**Toolpaths**) 옆 버튼)는 그림을 기술 도면처럼 보여 줍니다: 전체와 각 윤곽선(도형의 바깥쪽과 구멍을 각각 따로)의 너비와 높이, 원형인 것의 지름을 표시하며, 같은 것은 한 번에 묶어 표시합니다(**4 × Ø 6**). 그림은 전혀 바뀌지 않습니다.
* **자 (M)** 도구는 도형의 노드(사각형 표시), 구간의 중점(마름모 표시), 원이나 타원의 중심(원 표시)에 맞춰집니다. 원을 클릭하면 중심에서 클릭한 점까지의 반지름과 지름을 보여 주고, 타원에서는 두 반지름과 클릭한 점까지의 반지름을, 곡선에서는 그 길이를 보여 주며, 곡선이 원호이면 중심에서 클릭한 점까지 그린 반지름과 그 길이를 보여 줍니다.
* **노드 편집:** 노드나 구간을 오른쪽 클릭하면 노드 막대의 메뉴가 열립니다. **부드럽게**(**Smooth**)의 키는 **G**이며, **둥글게 (R)** 버튼 뒤에는 그 반지름이 표시됩니다.

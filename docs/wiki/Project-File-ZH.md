# 项目文件

BaseCreator 保存的是 **`.cre`**，即 LightCreator、MillCreator 和 PenCreator 也会写出的项目文件：一个 JSON 文件，包含图纸、描述以及**每个程序各自的一个部分**（`draw`、`laser`、`mill`、`pen`）。每个程序只写自己的部分，并保持其他部分不变，因此项目在程序之间传递时不会丢失任何内容。

`draw` 部分保存页面和 64 个图层（名称、颜色、是否显示）。

* 在这里创建的项目在其他程序中打开时，会带有图纸和描述。它们会保留 `draw`。
* 在那些程序中创建的项目在这里打开时会带有图纸。它会得到默认图层和最近一幅新图纸的页面，如果图纸放不下，页面会相应放大。在这里保存后，其机器设置仍保留在文件中。
* 如果文件中 `draw` 的格式较新，程序会拒绝打开，并提示更新程序。

## 创建者与贡献者

文件还会在 `authorship` 块中记录谁创建了项目、谁参与了项目：

* **创建者**（**Creator**）：第一个保存该项目的人。
* **贡献者**（**Contributors**）：其他所有保存过该项目的人，每人只添加一次。创建者会保存姓名、电子邮件和其他字段；贡献者（以及编辑记录）只保存姓名和电子邮件，如果电子邮件与创建者相同，则只保存姓名。
* **编辑记录**（**Edits**）：手动保存的记录（最近 200 条），同一个人在同一程序中每分钟最多记录一条。自动保存不会添加编辑记录。

每条记录包括姓名、电子邮件和一段自由文本（公司、网站……）、时间（UTC）以及程序及其版本。这些信息在 **设置 → 程序选项**（**Settings → Program options**）的 **作者**（**Author**）部分中设置：**你的姓名**（**Your name**）、**电子邮件**（**Email**）和 **其他**（**Other**）。它们保存在共享文件夹中的一个文件（`author.json`）里，因此在 BaseCreator、LightCreator、MillCreator 和 PenCreator 中都相同。如果没有姓名或电子邮件，保存时只记录时间和程序，不记录人员。

**文件 → 项目信息…**（**File → Project information…**）显示文件（名称、文件夹、大小、创建和修改时间）、作者（项目创建时间、创建者，其电子邮件和其他字段各占一行；贡献者及其电子邮件）以及编辑记录表：时间、人员、程序。

已有文件的项目会在每次更改约 20 秒后自动保存到该文件。参见[设置与文件](Settings-and-Files-ZH)。

## 密码保护

> ⚠️ 本节由英文版机器翻译而成。

项目可以用密码保护：在 LightCreator、MillCreator 和 PenCreator 的 **项目设置…**（**Project setup…**）中，以及 BaseCreator 的 **文件 → 页面设置…**（**File → Page setup…**）中的 **保护**（**Protection**）部分设置。

* **所有者密码**：可以做任何事（编辑、复制、导出、更改或移除保护）。
* **打开密码**（可选）：可以打开项目、查看、生成 G-code 并在机器上运行，也可以更改材料和图层设置（速度、功率、遍数、深度、刀具、笔），但不能编辑、复制、以图形格式导出（SVG、DXF、Illustrator、LightBurn …）或打印图形。此时内置网页不显示图形。
* 只有所有者密码时，其他人无法打开文件。没有密码文件完全无法读取，**忘记的密码无法找回**。
* 用打开密码打开的项目可以用所有者密码解锁，无需重新打开：在设置的 **保护** 部分（**所有者密码**、**解锁**），或在其标签页的菜单（右键）中选择 **用所有者密码解锁…**。该菜单还有 **项目信息…** 和项目设置。

文件仍是带有 `protected_cre` 键的 JSON 文本；其中的项目用 **XChaCha20-Poly1305** 以随机 256 位密钥加密，该密钥为每个密码各存一份，并用 **Argon2id**（64 MiB、3 遍、独立盐值）由密码生成的密钥加密。每次保存使用新的 nonce；被修改的文件无法打开。密码至少 8 个字符，打开密码必须与所有者密码不同。

打开密码所禁止的内容由程序执行，就像 PDF 的所有者密码一样：知道它的人原则上可以用其他工具解密项目。请自己保管好所有者密码。

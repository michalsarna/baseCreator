# 키보드 단축키

Mac에서는 Ctrl 대신 Cmd입니다. 키는 시작 화면이 아니라 편집기에서 동작하며, 텍스트 입력란에 키보드 입력이 들어가 있는 동안에는 어떤 키도 가로채지 않습니다.

## 메뉴의 키

| 키 | 명령 | 키 | 명령 |
|---|---|---|---|
| Ctrl+N | **새로 만들기**(**New**) | Ctrl+D | **복제**(**Duplicate**) |
| Ctrl+O | **열기…**(**Open…**) | Delete 또는 Backspace | **삭제**(**Delete**) |
| Ctrl+S | **저장**(**Save**) | Ctrl+A | **모두 선택**(**Select all**) |
| Ctrl+Shift+S | **다른 이름으로 저장…**(**Save as…**) | Ctrl+G | **그룹**(**Group**) |
| Ctrl+I | **SVG 가져오기…**(**Import SVG…**) | Ctrl+Shift+G | **그룹 해제**(**Ungroup**) |
| Ctrl+Q | **종료**(**Quit**) | Ctrl+L | **잠금**(**Lock**) |
| Ctrl+Z | **실행 취소**(**Undo**) | Ctrl+Shift+L | **잠금 해제**(**Unlock**) |
| Ctrl+Y 또는 Ctrl+Shift+Z | **다시 실행**(**Redo**) | Ctrl++ (Ctrl+=) | **확대**(**Zoom in**) |
| Ctrl+C | **복사**(**Copy**) | Ctrl+- | **축소**(**Zoom out**) |
| Ctrl+V | **붙여넣기**(**Paste**) | Ctrl+Shift+0 | **베드를 창에 맞추기**(**Fit bed to window**) |
| | | Ctrl+Shift+9 | **모든 객체 맞추기**(**Fit all objects**) |

## 그림 탭

| 키 | 하는 일 |
|---|---|
| Ctrl+1 … Ctrl+9, Ctrl+0 | 1번째 … 9번째 탭을 보여 주고, Ctrl+0은 10번째 탭을 보여 줍니다. |
| Ctrl+W | 표시 중인 그림을 닫습니다. 저장하지 않은 작업이 있으면 먼저 묻습니다. |

## 도구

| 키 | 도구 | 키 | 도구 |
|---|---|---|---|
| V | **선택 (V)**(**Select (V)**) | I | **나선 (I)**(**Spiral (I)**) |
| N | **노드 편집 (N)**(**Node edit (N)**) | L | **선 (L)**(**Line (L)**) |
| R | **사각형 (R)**(**Rectangle (R)**) | P | **폴리라인 / 펜 (P)**(**Polyline / pen (P)**) |
| E | **타원 (E)**(**Ellipse (E)**) | T | **텍스트 (T)**(**Text (T)**) |
| Y | **삼각형 (Y)**(**Triangle (Y)**) | H | **이동 (H)**(**Pan (H)**) |
| S | **별 (S)**(**Star (S)**) | Z | **확대 (Z)**(**Zoom in (Z)**) |
| G | **다각형 (G)**(**Polygon (G)**) | X | **축소 (X)**(**Zoom out (X)**) |
| K | **하트 (K)**(**Heart (K)**) | M | **자 (M)**(**Ruler (M)**) |

| 키 | 하는 일 |
|---|---|
| Esc | 선택을 해제합니다(그리고 그리는 중인 폴리라인도). |
| Esc 두 번 (0.5초 안에) | **선택 (V)** 도구로 돌아갑니다. |
| Space (누르고 있기) | 어떤 도구로든 화면을 이동합니다. 놓으면 원래 도구로 돌아갑니다. |
| 화살표 키 | 선택한 것을 1 mm 이동합니다. **Shift** + 화살표 = 10 mm. |
| G, I | 다각형과 나선: 작은 창에서 변의 수나 회전 수를 설정하며, 마지막으로 그린 도형에도 적용됩니다. |
| Enter | 그리는 중인 폴리라인을 끝냅니다. |

## 마우스와 키

| 동작 | 하는 일 |
|---|---|
| 작업 영역에서 휠(또는 핀치) | 포인터를 중심으로 확대/축소합니다. |
| 가운데 또는 오른쪽 버튼으로 끌기 | 작업 영역과 그 주변에서 보기를 이동합니다(움직이지 않은 오른쪽 클릭은 메뉴를 엽니다). |
| Shift+클릭 또는 Ctrl+클릭 | 도형을 선택에 추가하거나 선택에서 뺍니다. |
| 도형을 그리는 동안 Shift | 너비와 높이를 같게 유지합니다. |
| 모서리 핸들 끌기 | 비율을 유지합니다. Shift를 누르면 비율이 자유롭게 바뀝니다. |
| 회전하는 동안 Shift | 15° 단위로 회전합니다. |
| **폴리라인 / 펜 (P)** 도구로 오른쪽 클릭 또는 더블 클릭 | 폴리라인을 끝냅니다. 첫 점 근처를 클릭하면 닫힙니다. |
| 도형을 오른쪽 클릭 | 도형의 메뉴. |
| 탭을 가운데 클릭 | 탭을 닫습니다. |
| 창 사이의 선을 더블 클릭 | 창의 크기를 같게 만듭니다. |

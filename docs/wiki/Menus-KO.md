# 메뉴

메뉴 막대에는 일곱 개의 메뉴가 있습니다: **파일 · 편집 · 삽입 · 정렬 · 보기 · 설정 · 도움말**(**File · Edit · Insert · Arrange · View · Settings · Help**). 배치는 다른 프로그램과 같지만, 그 프로그램들의 **기계**(**Machine**) 메뉴와 공정 메뉴는 없습니다.

* **Windows와 Linux**에서는 메뉴 막대가 창 안에 있습니다. 시작 화면이 아니라 편집기에서 표시됩니다.
* **macOS**에서는 메뉴가 시스템 메뉴 막대에 있으며, 앱 메뉴 **BaseCreator**(**BaseCreator 정보**(**About BaseCreator**), **종료**(**Quit**))와 **윈도우**(**Window**)가 함께 있습니다.
* 지금 사용할 수 없는 항목은 회색입니다. 켜고 끄는 항목은 켜져 있을 때 체크 표시가 있습니다.

## 파일

| 항목 | 키 | 하는 일 |
|---|---|---|
| **새로 만들기**(**New**) | Ctrl+N | 자체 탭에 새로운 빈 그림을 만듭니다. |
| **열기…**(**Open…**) | Ctrl+O | 프로젝트, SVG, PDF 또는 Illustrator 파일을 새 탭으로 엽니다. DXF, LightBurn 또는 UGS 파일은 가져옵니다. |
| **최근 파일 열기**(**Open recent**) | | 최근 10개의 파일. **목록 지우기**(**Clear list**)는 목록을 비웁니다. |
| **저장**(**Save**) | Ctrl+S | 프로젝트를 `.cre`로 저장합니다. |
| **다른 이름으로 저장…**(**Save as…**) | Ctrl+Shift+S | 새 이름으로 저장합니다. |
| **프로젝트 정보…**(**Project information…**) | | 파일, 그 크기와 시각, 만든 사람, 기여자, 편집 기록. [프로젝트 파일](Project-File-KO)을 참고하십시오. |
| **페이지 설정…**(**Page setup…**) | | 페이지 크기. [페이지와 레이어](Page-and-Layers-KO)를 참고하십시오. |
| **가져오기 → …**(**Import → …**) | SVG는 Ctrl+I | [가져오기와 내보내기](Import-and-Export-KO)를 참고하십시오. **도형 생성…**(**Generate shape…**)은 플러그인의 생성기를 실행합니다. |
| **내보내기 → …**(**Export → …**) | | [가져오기와 내보내기](Import-and-Export-KO)를 참고하십시오. |
| **종료**(**Quit**) | Ctrl+Q | 프로그램을 닫습니다. 저장하지 않은 작업이 있는 그림은 먼저 하나씩 묻습니다. |

**인쇄…**(**Print…**, Ctrl+P)는 디자인을 종이 프린터로 인쇄하거나 PDF로 저장합니다.

## 편집

**실행 취소**(**Undo**, Ctrl+Z), **다시 실행**(**Redo**, Ctrl+Y), **복사**(**Copy**, Ctrl+C), **붙여넣기**(**Paste**, Ctrl+V), **복제**(**Duplicate**, Ctrl+D), **삭제**(**Delete**, Del), **모두 선택**(**Select all**, Ctrl+A).

## 삽입

페이지에 새 객체를 놓는 도구들, 그리고 **도형 생성…**(**Generate shape…**)과 **온라인 클립아트…**(**Online clipart…**). 새 도형은 사용 중인 레이어에 들어갑니다.

## 정렬

같은 명령이 도형의 오른쪽 클릭 메뉴에도 있으며, [디자인 도구](Design-Tools-KO)에서 설명합니다.

* **왼쪽 맞춤**(**Align left**), **가운데 맞춤 (H)**(**Align centre (H)**), **오른쪽 맞춤**(**Align right**), **위쪽 맞춤**(**Align top**), **가운데 맞춤 (V)**(**Align centre (V)**), **아래쪽 맞춤**(**Align bottom**), **베드 중앙에 배치**(**Centre on bed**, 페이지의 가운데), **서로 중앙 맞춤**(**Centre on each other**)
* **좌우 뒤집기**(**Flip horizontal**), **상하 뒤집기**(**Flip vertical**), **시계 방향 90° 회전**(**Rotate 90° CW**), **반시계 방향 90° 회전**(**Rotate 90° CCW**)
* **그룹**(**Group**, Ctrl+G), **그룹 해제**(**Ungroup**, Ctrl+Shift+G), **잠금**(**Lock**, Ctrl+L), **잠금 해제**(**Unlock**, Ctrl+Shift+L), **맨 앞으로 가져오기**(**Bring to front**), **맨 뒤로 보내기**(**Send to back**)
* **노드 편집**(**Edit nodes**, N), **경로로 변환**(**Convert to path**)
* **합치기**(**Union**), **교차**(**Intersection**), **빼기**(**Subtract**), **배타적 논리합**(**Exclusive or**), **도형 오프셋…**(**Offset shape…**), **모서리 둥글게…**(**Round corners…**), **곡선으로 변환**(**Convert to curves**)
* **경로 자동 연결…**(**Auto-join paths…**), **허용 오차로 경로 닫기…**(**Close path with tolerance…**), **도그본 / T본 모서리…**(**Dogbone / T-bone corners…**)
* **격자 배열…**(**Grid array…**), **원형 배열…**(**Circular array…**), **경로를 따라 복사…**(**Copy along path…**), **경로 위 텍스트…**(**Text on path…**)
* **도형으로 자르기…**(**Trim by shape…**), **중복 제거**(**Remove duplicates**), **분해**(**Break apart**), **단순화…**(**Simplify…**)
* **일련번호 텍스트…**(**Serial text…**), **바코드 / QR 코드…**(**Barcode / QR code…**), **도형 배치(네스팅)…**(**Nest shapes…**), **측정…**(**Measure…**)
* **이미지 조정…**(**Adjust image…**), **이미지 편집…**(**Edit image…**, 사진 편집기), **이미지 트레이스…**(**Trace image…**)
* **스타일 트레이스…**(**Style trace…**): 선택한 그림을 21가지 스타일 중 하나의 선으로 다시 그립니다([스타일 트레이스](Style-Trace-KO)).
* **기하학적 다각형…**(**Geometric polygons…**): 선택한 그림을 사이에 간격이 있는 기하학적 다각형으로 만듭니다(그 스타일이 선택된 스타일 트레이스 창).
* **이미지로 변환…**(**Convert to image…**): 선택한 도형을 하나의 그림으로 만듭니다.

## 설정

| 항목 | 하는 일 |
|---|---|
| **보기 옵션…**(**View options…**) | 그리드, 작업 영역의 색, 선 두께, **레이어 이름 표시**(**Show layer names**). |
| **프로그램 옵션…**(**Program options…**) | **프로그램 시작 시 새 버전 확인**(**Look for a newer version when the program starts**, 기본값은 켜짐), 그리고 **웹 서버와 API**(**web server and API**): 프로젝트가 담긴 페이지(그림을 따라 바뀌는 SVG)와 `http://localhost:8768`의 API(기본값은 꺼짐. 포트, 네트워크의 다른 컴퓨터 허용, 그리고 접근 문구를 설정합니다. 접근 문구는 처음에 `BaseCreator`이며, 브라우저가 아무 사용자 이름과 함께 묻습니다). 다른 프로그램에도 같은 서버가 8765(LightCreator), 8766(MillCreator), 8767(PenCreator) 포트에 있습니다. |
| **플러그인…**(**Plugins…**) | [플러그인](Plugins-KO)을 참고하십시오. |
| **언어**(**Language**) | 38개 언어. |
| **색 구성표**(**Colour scheme**) | 18개의 색 구성표, 그리고 크리스마스, 새해, 핼러윈, 부활절, 춘절 무렵의 축제용 구성표 두 개. |

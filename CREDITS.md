# Credits

baseCreator carries code and assets that come from LightCreator; the credits below are the ones that apply here.
Licences are named for orientation; the exact terms are in each project's repository.

* **[resvg / usvg](https://github.com/linebender/resvg)** (MPL-2.0): reading SVG and its font database for text outlines.
* **[lopdf](https://github.com/J-F-Liu/lopdf)** (MIT): reading Illustrator / PDF files.
* **[roxmltree](https://github.com/RazrFalcon/roxmltree)** (MIT OR Apache-2.0): reading LightBurn projects (XML).
* **[i_overlay](https://github.com/iShape-Rust/iOverlay)** (MIT): boolean operations on shapes.
* **[ttf-parser](https://github.com/harfbuzz/ttf-parser)** (MIT / Apache-2.0): outlines of text for engraving.
* **[image](https://github.com/image-rs/image)** (MIT / Apache-2.0): PNG, JPEG, BMP, GIF and WebP pictures.
* **[serde](https://serde.rs/)**, **serde_json** and **base64** (MIT / Apache-2.0): saved data and embedded pictures.
* **[Noto fonts](https://fonts.google.com/noto)** (Google and the Noto Authors, SIL Open Font License 1.1): the fonts built into the text tool
  (Latin, Cyrillic, Greek, Chinese, Hindi; licence in `assets/fonts/OFL.txt`).
* **[egui](https://github.com/emilk/egui)** by Emil Ernerfeldt and contributors (MIT / Apache-2.0): the interface toolkit.
* **[nokhwa](https://github.com/l1npengtul/nokhwa)** (Apache-2.0): optional live camera capture.
* **[ureq](https://github.com/algesten/ureq)** (MIT / Apache-2.0): the camera stream.
* **[Lucide](https://lucide.dev)** (ISC): the interface icons (`assets/ui-icons`, licence in `assets/ui-icons/LICENSE-lucide.txt`); two icons drawn in the same style.
* **[muda](https://github.com/tauri-apps/muda)** (Tauri, MIT / Apache-2.0) and **[objc2](https://github.com/madsmtm/objc2)** (MIT): the native macOS menu bar.
* **[rfd](https://github.com/PolyMeilex/rfd)** (MIT): native file dialogs.
* **[Material Design Icons](https://github.com/Templarian/MaterialDesign-SVG)** by Pictogrammers (Apache-2.0) and the **[Iconify](https://iconify.design)** search service: the clipart gallery (`assets/clipart`).
